The Surveillance Dilemma

  • Crowd Occlusions: Targets hide behind pillars; basic trackers lose identity instantly.
  • Environmental Chaos: Shadows, blur, and 45° angles destroy standard pixel matching.
  • Static Thresholds: Guessing a "50% match" rule causes false arrests in the dark.
  • Browser Overload: Traditional Base64 evidence rendering freezes police laptops.

5-Phase Architecture

  • Phase 1: Biometric Encoding — RetinaFace + ArcFace (512D)
  • Phase 2: Kinetic Localization — YOLOv8 + ByteTrack
  • Phase 3: Unsupervised Selection — Autonomous Spectral Gap Engine
  • Phase 4: Evidence Synthesis — 3x Slow-Motion Reconstructor
  • Phase 5: Zero-Lag UI — Streamlit + Native Disk Sockets

Solving Crowd Occlusion

YOLOv8 + ByteTrack

  • YOLOv8: Real-time bounding box detection.
  • ByteTrack: Uses Kalman Filters to predict movement.
  • Result: Unlike DeepSORT, ByteTrack keeps target IDs alive even when completely hidden by a crowd!

Biometric Invariance

RetinaFace + ArcFace

  • RetinaFace: 5-point alignment straightens tilted faces automatically.
  • ArcFace 512D: Rejects outdated FaceNet. Maps faces to a strict mathematical sphere.
  • Result: 90%+ Accuracy maintained in low light and heavy makeup.

Removing Human Error
